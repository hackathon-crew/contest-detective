# Agent recommendation preview

在前端目录启动 `npm run dev -- --host 127.0.0.1 --port 5184`，打开：

- `http://127.0.0.1:5184/agent-preview.html`：画像文件及推荐卡片。
- `http://127.0.0.1:5184/agent-preview.html?profile=off`：直接提问，无画像的推荐卡片。

预览复用正式的侦探页面、消息、会话列表、输入框及赛事详情组件。可点画像文件检查结构化内容，刷新后通过同一浏览器的 localStorage 恢复。通过输入框左侧入口生成并确认画像后，预览会回到同一对话，显示新的画像文件与候选推荐。

比赛字段是 2026-10-24 公共赛事 API 的快照，保留原始出处、核实等级和日期精度；封面使用现有赛事海报。介绍与推荐理由为固定的预览文案。模型回复、搜索步骤和 GitHub 画像生成均为固定数据，不发起模型、搜索或真实画像请求。

此入口不由正式 `main.tsx` 引用，也不包含在默认生产构建中。正式侦探通过 SSE 返回模型选中的比赛、简介与推荐理由，卡片基础信息由比赛库提供，和文字一起保存。画像附件的服务端文件存储与生成工具尚未接入；预览中的画像流程仍使用固定数据。
