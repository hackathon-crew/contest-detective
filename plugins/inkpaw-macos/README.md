# Inkpaw Companion for macOS

独立的 macOS 原生比赛助手，使用 SwiftUI、AppKit 和 RealityKit，不嵌入网页。

当前提供功能源代码与测试；尚未完成 macOS SDK 编译和 GUI 验证，也没有签名、公证或正式发行包。Linux 检查不能替代原生验证。

## 功能

- 可拖动、收起的桌面章鱼与菜单栏入口；单独的原生工作台。
- 录入比赛起止时间、IANA 时区和节点，显示绝对时间倒计时。仅知道日期时明确标记待核实，不推测准确时刻。
- 蓝色八腕、黑贝雷帽的程序化 3D Inkpaw，带书和放大镜；位置只对应赛程经过比例，清单完成率独立显示。支持系统“减少动态效果”。
- 按比赛管理提交清单，保存赛程、资料和窗口状态。
- 导入本地 TXT、Markdown、文本型 PDF；逐个选择原文片段，预览目标服务与实际发送内容后，进行带原文出处的模型问答。
- 只读查看选定 Git 项目的状态、近期提交、相对本地 tracking ref 的领先/落后，以及有明确本机 reflog 证据的 push 记录。不会 fetch、commit、push 或修改项目。
- 主动开启系统通知后，提前 1 小时、15 分钟和到点提醒；重排旧节点，保存已送达标识，最多安排最近 64 条通知。

## 构建与运行

需要 macOS 15+，以及提供 Swift 6 的 Xcode 命令行工具。没有第三方 Swift 依赖。

```sh
cd plugins/inkpaw-macos
swift test
bash scripts/package-app.sh
open .build/unsigned/InkpawCompanion.app
```

打包脚本只在本目录 `.build/unsigned` 内生成开发用 `.app` 和 ZIP，不安装到系统位置，不签名、不公证、不发布。原生通知要求从该 `.app` 启动；直接 `swift run InkpawCompanion` 可以调试窗口，但通知会明确提示需要应用包。

菜单栏可以打开工作台、显示或隐藏挂件、退出应用。退出时保存本地状态。关闭工作台窗口不会退出挂件。已安排的系统通知可在退出后触发；要取消它们，请先关闭提醒开关。

## 规则文档问答

1. 在“服务与提醒”配置自己的 Inkpaw 服务地址，例如开发环境 `http://127.0.0.1:8000`，或已部署服务的 HTTPS `/api` 地址。
2. 使用已有账号主动登录。密码不保存，会话独立于浏览器并仅保存在内存；重启后重新登录。
3. 导入文件。导入与原文查找只在本机进行；扫描 PDF 不提供 OCR，包含无可提取文字页面的 PDF 会明确拒绝，不静默遗漏页面。
4. 选择最多 8 个相关片段，填写问题，点击“预览并发送”。只有确认的片段与问题会发往保存的服务及其模型。
5. 每条回答附精确原文引用，可打开完整片段。来源不足或引用校验失败时不显示猜测答案。引用逐字匹配并不等于模型解释一定正确，仍应核对完整规则。

服务端须包含 `POST /companion/documents/ask`。它复用当前账户 cookie、现有 `DETECTIVE_LLM_*` 配置及费用预算，单次受限调用，无研究工具，不持久化文档、问题或答案，不修改赛事库；保留必要的模型用量账本。旧版服务器或未启用模型时明确报错，不退回可写数据的 `/agent/ask`。本插件不会自动部署服务器、增加凭据或开通付费服务。

请求上限为 24 KiB：问题最多 1,000 个 Unicode 标量，1–8 个片段，每个片段最多 4,000 个。远程服务必须 HTTPS；仅明确 loopback 地址允许 HTTP；所有 HTTP 重定向被阻止。模型问答可能使用服务原有额度，开发测试仅用合成材料和假模型。

## Git 证据边界

- 只在你选定的项目内读取 Git 状态和历史。状态检查可能在本机读取、散列工作区文件；不会把文件内容、路径或 Git 记录发往问答服务，也不扫描其他项目。
- tracking ref 可能陈旧，领先/落后不是实时远端核验。本插件不自动联网更新它。
- push 列表只接受 remote-tracking reflog 中明确的 `update by push` 记录。这是本机观察到的证据，不是完整的 GitHub 推送历史；没有证据时显示未知。
- 支持空仓库、detached HEAD、linked worktree、无 upstream、嵌套分支及不常见的 remote 名称；歧义映射不猜测。
- 为避免 Git 隐式执行过滤器或联网，配置了可执行过滤器、局部配置 include、partial/promisor clone 的仓库会明确拒绝读取；不会伪造一个“零变更”快照。传输与惰性抓取另外被禁用。

## 本地数据与权限

赛程、清单、导入文本和项目目录保存到 `~/Library/Application Support/InkpawCompanion/state.json`，原子写入并限制文件权限。原文件不会因为“移除文档”按钮而被删除。损坏、超大或未知版本的状态文件会阻止覆盖；通过设置页在 Finder 中定位，恢复或移走文件后再启动。

应用不请求辅助功能、屏幕录制、摄像头、通讯录或新的账号权限。通知权限只在点击启用时请求。规则原文保存在本机，请不要把本地状态文件作为公开诊断材料。

## 检查

```sh
# macOS：包含原生通知适配器与工作台状态测试
swift test
bash scripts/package-app.sh

# Linux：仅平台无关领域、文档 HTTP 适配器、Git、存储与姿态数学
swift test
```

macOS 工作流会执行原生编译、测试和无签名打包，并保留短期构建产物。拖动、焦点、多屏、实际 3D 渲染、通知展示及首次启动仍需真实 macOS GUI 验证；尚未做过的检查不能视为已通过。
