# 比赛侦探

面向大学生的比赛发现与核实工具。用户给出筛选条件，agent 检索公众号和赛事官网，输出经过核实的比赛信息。

## 要解决的问题

比赛信息分散在各个公众号和聚合站里，转载内容经常过时。同一个比赛，转载文章写的截止日期和官网公告不一致的情况并不少见，延期、改赛制、追加赛道之后，旧的转载仍然在流传。学生拿到一条比赛信息，很难判断它是否可信、是否已经过期，只能自己逐条追到官网去核对。

现有的比赛聚合站只收录在其平台上发布的比赛，企业和社区举办的比赛有很大一部分只在公众号和官网发布。本项目检索全网公开信息，并对每一条结果核实来源。

## 功能

- **条件筛选**：按参赛形式（线上或线下）、截止时间范围筛选，并可排除指定的比赛类型。
- **结构化输出**：每个比赛生成一张卡片，包含主办方、截止时间、参赛形式、报名链接和是否收费。
- **来源核实**：每张卡片附带证据链，标明信息出处、是否追溯到官方页面、不同来源的截止日期是否冲突。

## 首版范围

首版只做一次查询的完整流程：输入条件，检索，抽取字段，核实，输出卡片。账号体系、订阅推送和长期维护的比赛数据库不在首版范围内。

## 待验证的技术问题

- **搜索源**：候选搜索服务的接口、额度和中文结果质量需要实测，搜索层做成可替换的接口，避免绑定单一服务。
- **公众号原文获取**：公众号文章常有反爬限制，需要验证各搜索源能否返回正文或可访问的原文链接。拿不到正文时，卡片只展示摘要，并标记为未核实。
- **核实准确率**：用一组已人工核实过的比赛作为样本，检验抽取的截止日期和主办方是否正确，以及日期冲突能否被检出。
